Comparación de códigos para integración por método de trapecio

Primordialmente, vamos a analizar el código que tenemos en el libro de Computational Physics de Rubin H. Landau, Manuel J. Páez, y Cristian C. Bordeianu: 

        
        from numpy import *
        import matplotlib.pyplot as plt
        
        def func(x):
            return 5*x*exp(3)-4*x+7
        
        def trapezoid(A,B,N):
            h = (B-A)/(N-1)
            sum = (func(A)+func(B))/2
            for i in range(1,N-1):
                sum += func(A+i*h)
            return h*sum
        
        A = 0
        B = 1
        N = 10
        print(trapezoid(A, B, N-1))
