Primordialmente, vamos a analizar el código que tenemos en el libro de Computational Physics de Rubin H. Landau, Manuel J. Páez, y Cristian C. Bordeianu.
Para la prueba de este código utilizaremos la función:

\[ 5x e^3 - 4x + 7 \]

Esta función la vamos a evaluar utilizando los dos códigos de programación, con límites de 0 hasta 1 para ambos códigos de programación. El resultado para esta es: 55.21375 

        
        from numpy import *
        import matplotlib.pyplot as plt
        
        def func(x):
            return 5*x*exp(3)-4*x+7
        
        def trapezoid(A,B,N):
            h = (B-A)/(N-1)
            sum = (func(A)+func(B))/2
            for i in range(1,N-1):
                sum += func(A+i*h)
          return h*sum
        
          a = 0
          b = 1
          n = 100
          
          res1 = trapezoid(func, a, b, n)
          print("Resultado trapezoid:", res1)
          #Obteniendo como resultado: 55.21384230796919

Este código es un poco más "sencillo" a comparación del que mostraremos después, sin embargo, es menos eficiente ya que utiliza bucles manuales por otro lado, coincide casi exactamente con el resultado,
se sacrifica eficiencia a cambio de exactitud.

Luego, tenemos un código obtenido en clase de Física computacional l utilizando el mismo método y el código es:

       
        from numpy import *
        import numpy as np
        import matplotlib.pyplot as plt

        def func(x):
          return 5 * x * exp(3) - 4 * x + 7

        def trapezoid_rule(f, _a, _b, n):
          x = np.linspace(_a, _b, n + 1, endpoint=False)
          y = f(x)
          h = (_b - _a) / n
          return (h / 2) * (y[0] + 2 * np.sum(y[1:]) + y[-1])

          a = 0
          b = 1
          n = 100


          res2= trapezoid_rule(func, a, b, n)

          print("Resultado trapezoid_rule:", res2)
          #Obteniendo como resultado: 55.7612070832956

Como podemos notar, para este caso este código es más eficiente ya que usa operaciones vectorizadas, sin embargo, aquí pasa al revés, se sacrifica exactitud por eficiencia.
